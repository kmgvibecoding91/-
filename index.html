Пакетное переименование PDF-файлов по списку из Excel

Строка 1 списка соответствует первому файлу в папке, строка 2 — второму и так далее. В именах могут быть персональные данные, поэтому всё работает локально, а каждое действие видно заранее и обратимо.

Работает в браузере без сети. Ваши данные никуда не отправляются.

Приоритеты

  1. Безопасность данных: ничего не перезаписывается и не удаляется
  2. Конфиденциальность: без сети, маскирование имён в логе
  3. Простота: подсказки и готовые варианты ответа

Семь этапов работы

Каждый этап записывается в лог как [ЭТАП N/7] … НАЧАТ / ЗАВЕРШЁН / ПРЕРВАН. Если этап прерван, следующий не начинается.

ЭТАП 1
Запуск
Меню: переименовать, откатить или выйти. Создаётся лог.
ЭТАП 2
Параметры
Пути к Excel и папке. Проверка прав и запрет системных папок.
ЭТАП 3
Чтение Excel
Только чтение. Макросы не выполняются, формулы берутся как значения.
ЭТАП 4
Сканирование
Только *.pdf в папке без вложенных. Естественная сортировка.
ЭТАП 5
План
Сопоставление по порядку. Вопрос по каждой найденной проблеме.
ЭТАП 6
Предпросмотр
Таблица «старое → новое». Подтверждение только словом ДА.
ЭТАП 7
Выполнение
Сначала файл отката, потом переименование в две фазы, затем сводка.

Принятые решения

Р1

Естественная сортировка

Файл file2 идёт перед file10, поэтому сопоставление не сдвигается.

Р2

Двойной клик по run.bat

Python 3.10+ и Windows 10/11. Параметры вводятся по подсказкам, командная строка не нужна.

Р3

Вопрос по каждой проблеме

Скрипт ничего не решает молча: на каждую проблему есть пронумерованные варианты ответа.

Р4

Сначала план

Пары «старое → новое» видны до изменений, это защищает от ошибки сопоставления.

Безопасность и целостность

Двухфазное переименование

Цепочка a→b, b→a без промежуточного шага вызвала бы конфликт уже на первой операции.

a.pdf
b.pdf
→ фаза 1 →
~tmp_9f…pdf
~tmp_c2…pdf
→ фаза 2 →
b.pdf
a.pdf

Журнал отката записывается на диск до каждой операции. Если работа прервётся, по файлам ~tmp_*.pdf можно восстановить исходные имена.

Что запрещено

  • Сеть, телеметрия, обновления, облачные API
  • Чтение содержимого PDF (работа только с именами)
  • Удаление, перемещение, копирование и перезапись файлов
  • Выход из папки: .., разделители путей, абсолютные пути
  • Изменение Excel-файла, выполнение макросов
  • eval, exec, os.system, subprocess

Логи и персональные данные

  • По выбору имена маскируются: Ив***.pdf
  • Файл отката всегда содержит полные имена (в нём есть ПДн)
  • Логи хранятся в rename_logs рядом со скриптом
  • Защита от CSV-инъекций: перед = + - @ ставится апостроф

Пример лога

2026-10-14 10:15:02 | INFO    | ЭТАП 3/7 | ЗАВЕРШЁН: прочитано 48 имён
2026-10-14 10:15:40 | WARNING | ЭТАП 5/7 | Дубликат в строке 17 → выбрано: добавить суффикс
2026-10-14 10:16:05 | INFO    | ЭТАП 7/7 | OK: scan_003.pdf → Ив***.pdf
